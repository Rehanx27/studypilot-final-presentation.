MATHEMATICS · SAMPLE CONCEPT

What does a variable do?

A variable is a letter or symbol that stands for a number. Think of it like an empty box: its value can change, but once we know the value, we can calculate with it.

If x = 4, then x + 3 = 7

Try it: If y = 6, what is the value of 2y + 1?

Explanation: replace y with 6, so 2 × 6 + 1 = 13. A complete question bank needs original questions mapped to verified topics and reviewed for accuracy.

What a production release needs

Four practical completion gates.

01 · Verify official sources

Record academic year, class, version, subject, official textbook title, source URL and review date.

02 · Map every chapter

Enter exact chapter and topic titles in printed order; do not assume the Bangla and English versions match.

03 · Review practice

Create original questions with correct answers, explanations, difficulty and reviewer status.

04 · Test before launch

Verify authentication, student/admin permissions, backups and privacy safeguards. Get appropriate school/guardian approval before a student pilot.

Official source directory: NCTB 2026 textbook index. The index helps locate books; it does not prove this demo has verified every chapter.
